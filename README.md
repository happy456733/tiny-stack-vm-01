A tiny stack virtual machine in one small `main.ts`: it runs all 40 programs of a set from `/input/<id>/program.bin` + `input.bin` and writes `/output/<id>/stdout.bin` and `/output/<id>/exit.txt` for each — 32-bit wrapping arithmetic, a 256-value stack, calls, 256 words of memory, input/output, and all ten traps with their own exit codes.

## Run it

```sh
node main.ts
```
